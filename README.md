# Projeto Energia Termica CC1P33
Repositorio para fazer o gerenciamento e desenvolvimento e entrega do projeto que é uma pagina web interativa sobre a energia termica.

Este projeto foi desenvolvido como atividade acadêmica com o objetivo de apresentar conceitos relacionados à energia térmica, seu funcionamento, aplicações no cotidiano e sua relação com a sustentabilidade ambiental.

Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
